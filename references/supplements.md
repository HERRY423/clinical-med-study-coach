# 补充环节（教练补充，原文未覆盖）

> ⚠️ 本文件不是那位学长/学姐的原话，是教练在其方法基础上**补充的环节**，用来覆盖原文止步的地方（原文主要写到大一大二的专业课与备考）。给学生讲这部分时，**主动说明"这是补充建议"**，并尽量沿用原文的底层逻辑（跟着老师定位重点、有策略地重复、真题导向、不写大段笔记、用图理脉络）。

---

## 一、错题系统化

原文有"刷题→做错的回书上标记/再看一遍→考前过错题"，但没成体系。补一套**贴合原文风格**的轻量系统（核心是不另起厚厚的错题本，避免大段抄写）：

**归因分类**（每道错题先判断错在哪类，这比"重做"更重要）：
1. **知识点漏洞**——压根没掌握 → 回书/ppt 补，标记原处。
2. **审题失误**——看错条件、被情境绕进去（生化、临床高发）→ 在题干上圈出关键词，写一句"这题在考 ___"。
3. **计算/推导失误**——步骤错（酸碱平衡这类）→ 把正确步骤写在题边，标"再做一遍"。
4. **记忆错误**——记混了、概念差一两个词 → 进"易混对比"清单（见下）。

**怎么记、记多少**（关键：克制）：
- 只收录**反复错的**和**高频考的**，错一次就会的不进系统。
- 优先用**书上/题库上原地标记**（折角、荧光、旁批关键词），而不是另起本子——和原文"不写大段笔记、笔记记书上"一致。
- 单独维护一张**"易混概念对比表"**（差一两个词就天差地别的那些），考前反复看。

**和三轮复习挂钩**：
- 第一轮：边刷边标错、即时归因。
- 第二轮：把高频错题的知识点并进思维导图。
- 第三轮（考前 2–3 天 / 几小时）：**只重做反复错的 + 过一遍所有标记**，不再铺新题。

## 二、基础医学 → 临床的衔接

原文止于大二专业课。进入见习/实习前，知识要从"按学科竖着学"转成"按疾病横着串"：

**以疾病为中心重组知识**——把零散的基础知识挂到一条临床链上：
> 病因 → **病理生理机制**（代偿/失代偿，用原文的流程图思维画出来）→ 临床表现（症状/体征是机制的外在表现）→ 诊断（查体 + 检验 + 影像）→ **药理/治疗**（针对哪个机制环节起效）。

**迁移原文已有的工具**：
- 思维导图/流程图：从"理解一章机制"升级为"串起一种疾病的完整逻辑链"。
- "脱书画流程图、画卡住=没懂"的检验法，直接用来自测临床推理。
- "现象→本质机制→联系起来"的答题格式，天然适合病例分析题和临床思维。

**衔接动作**：每学完一个系统，挑 3–5 个代表性疾病，各画一张"从机制到治疗"的整合图；见习遇到真实病人时，反推他对应哪条链、卡在哪一环。

## 三、见习 / 科研 / 文献入门（简要指引）

原文提到"大一大二科研没太多成就，跟基础老师搞了点生信，大三做得多"，但未展开。给想早点起步的同学的最小可行建议：

- **科研起步**：先跟一个方向明确、肯带人的老师，从能上手的活做起（如生信/数据整理/文献阅读），别一上来追求大成果；和"跟着老师学、先把基础打通"同理。
- **文献入门**：从中文综述 → 高质量英文综述 → 原始研究，循序渐进；用"读你不太理解的地方、反复琢磨"的老办法啃。
- **见习心态**：把课堂机制和床旁现象对上号，是巩固基础最高效的方式；带着"这个病人对应我学过的哪条链"的问题去看。

> 这块原文信息少，回答时不要硬编细节；可坦诚说"这部分学长原文没展开"，给方向性建议，并鼓励对方找本校/本科室的具体经验帖和带教老师。

## 四、4 年长期 / 保研视角

原文反复强调"每一分都可能影响保研""核心课非核心课对我都重要""久久为功"——把它显式化为长期策略：

- **绩点是复利**：早期（大一大二）课相对少，是把绩点拉高、攒安全垫的窗口期；高年级课密、出错成本高。
- **平时分先行**：每门课开学就摸清平时分构成（作业/考勤/实验/展示占比），把这部分**稳稳全拿**，等于给期末减压。
- **时间来得及就做到好**：在保大头的前提下，连 PBL、非核心课这种也尽量拿高分——因为最终都折进保研。
- **科研与绩点并行**：低年级以绩点为主、科研轻量起步；高年级再加大科研投入。
- **可持续**：原文也反思过"当时太不懂得享受、对自己再好一点"——长期主义不等于把自己耗干，状态管理（见 habits-and-energy.md）是长跑的一部分。
